     1→# AdSpy Lite — Project Worklog
     2→
     3→## Project Overview
     4→AdSpy Lite is a companion web dashboard for a Chrome Extension that scrapes/saves Facebook & Instagram ads from the Meta Ad Library. Built for digital marketers, agencies, and e-commerce sellers doing competitor research.
     5→
     6→Sunset Color Palette: #EA6113 (deep orange), #F88F22 (orange), #FBB931 (amber), #FFE3B3 (cream)
     7→
     8→## Tech Stack
     9→- Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui
    10→- Zustand (client state), Recharts (charts), Framer Motion (animations), Lucide icons
    11→- Single-page app with client-side view routing (only `/` route exposed)
    12→
    13→## Architecture
    14→Single-page application with view-state management via Zustand. Views:
    15→- Landing (hero, features, pricing, testimonials, CTA)
    16→- Dashboard (overview stats, recent activity, tracked competitors)
    17→- Saved Ads (grid collection, folders, tags, search, filter, export)
    18→- Competitors (tracker list with ad counts, longevity, status)
    19→- Analytics (ad pattern trends, CTA words, formats, color usage)
    20→- Swipe File (inspiration board, shareable collections)
    21→- Team (agency workspace, members, roles)
    22→- Admin (system overview, users, subscriptions, health)
    23→- Settings (account, notifications, sync)
    24→- Billing (plans, invoices, payment methods)
    25→
    26→Role switcher: Free / Pro / Agency Owner / Team Member / Admin
